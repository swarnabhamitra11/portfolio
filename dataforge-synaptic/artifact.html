What the toy model shows

The vertical marker is the selected representation dimension. The curve estimates mean cosine similarity after writing N random associations into one dense outer-product memory matrix.

The update rule

Wₜ = λ Wₜ₋₁ + η (Vₜ ⊗ Kₜᵀ)

The same fixed-shaped state is reused as new information arrives. The attraction is constant state size; the trade-off is that different associations occupy the same representational space.

Where BDH enters

The Pathway BDH paper describes working memory during inference as relying on synaptic plasticity with Hebbian learning, and emphasizes sparse, positive activation. This explainer uses those ideas as the bridge from classical associative memory to a post-Transformer architecture.
